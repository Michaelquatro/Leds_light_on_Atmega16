# Лабораторная работа №3: Управление индикацией на ATmega16

##  Описание проекта

Данный проект реализует систему управления светодиодной индикацией на базе микроконтроллера **ATmega16**. 

С помощью кнопки, подключенной к пину **PC0**, пользователь может переключать состояние индикатора:
- **Первое нажатие** — зажигает светодиоды, формирующие символ **«Н»**
- **Повторное нажатие** — гасит все светодиоды

Переключение происходит по фронту нажатия кнопки (переход с высокого уровня на низкий).

##  Аппаратное обеспечение

### Микроконтроллер
- **Модель:** ATmega16
- **Тактовая частота:** 8 МГц

### Органы управления
- **Кнопка без фиксации** на пине **PC0**
- Подтяжка к VCC через внутреннее сопротивление микроконтроллера
- При нажатии кнопка замыкает пин на землю (логический 0)

### Исполнительные устройства
Светодиоды подключены к следующим портам:
- **PORTA** (PA0-PA7) — все 8 светодиодов
- **PORTB** (PB3, PB4) — 2 светодиода
- **PORTC** (PC3, PC4) — 2 светодиода  
- **PORTD** (PD0-PD7) — все 8 светодиодов

**Формируемый символ:** Буква **«Н»**
- Вертикальные линии: PORTA и PORTD (все 8 бит)
- Горизонтальная перемычка: PORTB и PORTC (биты 3 и 4)
